# Koma

大学の時間割と、出席・FS・課題を管理する iOS アプリ。
SwiftUI + SwiftData / iOS 18.0 以降。UI の言語は英語。

プライバシーポリシーは [PRIVACY.md](PRIVACY.md)。データは端末内だけで、通信もアカウントもない。

## 開く

```sh
open /Users/youmi/Dev/Koma/Koma.xcodeproj
```

Bundle ID は `io.ngs.Koma`。実機で動かすときは Signing & Capabilities で Team を選ぶ。

## 構成

| 場所 | 役割 |
| --- | --- |
| `Koma/Models` | `Semester` / `Course` / `Meeting` / `TaskItem`（SwiftData） |
| `Koma/Services` | やることの生成（`TaskScheduler`）・仕分け（`TaskBoard`）・通知（`NotificationManager`） |
| `Koma/Views/Timetable` | 時間割タブ（今日の授業 + 週表） |
| `Koma/Views/Courses` | 授業の一覧・詳細・編集 |
| `Koma/Views/Tasks` | やること一覧・History・手動追加 |
| `Koma/Views/Settings` | 学期・コマの時間・通知 |

## リマインドの4種類

いずれも授業ごとにオン／オフとタイミングを変えられる。

課題と最終課題は、**提出期限と通知タイミングを別々に**設定する。

| 種類 | 期限 | 通知 | 既定 |
| --- | --- | --- | --- |
| Attendance | 授業開始から受付N分 | 授業開始からN分後 | 受付5分 / 開始と同時 |
| FS | 授業の2日後 **23:59**（全授業で固定） | 期限の当日、指定した時刻 | 19:00 |
| Assignment（毎週） | **次の授業の開始まで** か 授業の N 日後 + 時刻 | 期限の N 日前 + 時刻 | 6日後 23:59 / 1日前 19:00（既定オフ） |
| Final project | 日時を直接指定 | 期限の N 日前 + 時刻 | 7日前 19:00（既定オフ） |
| Exam | 日時を直接指定 | **2回**（N日前 と M日前）+ 時刻 | 7日前・前日 19:00 |

課題の期限は Deadline で2通りから選ぶ。

- **Days after class** — 授業の N 日後の指定時刻
- **Before next class** — 次の授業が始まるまで。コマの時間を変えれば期限も一緒に動く。学期最後の回だけは次が無いので1週間後の同時刻を期限にする

## 2時間続きのコマ

同じ授業が連続した限に入っている場合（1限+2限など）は、1回の授業として扱う。

- 期限の「次の授業」は**次の授業日**を指す。同じ日の2限は拾わない
- **出席と FS はコマごとに1件**。出席は限ごとに押す必要があり、FS も1コマにつき1枚書くため
  （1限+2限なら出席2件・FS 2件。行には `P1` `P2` のバッジが付く）
- 課題は1日につき1件。基準はその日の最初のコマの開始時刻
- 今日の授業カードは `P1–P2 8:40–11:50` とまとめ、締切は `Check in each period by 8:45 · 10:25` と両方出す

FS の表示名などは変更できない（変えられるのは Final project のタイトルだけ）。

## To-Do タブの並び

いま手を動かせるものだけを出す。

タブバーのバッジは **To-Do に並ぶ件数**（`TaskBoard.Groups.count`）。期限切れの数ではない。

上のセグメントで **To-Do / Missed / Done** を切り替える。
その下に `4 to do · 10 missed · 23 done` と件数をまとめて出す（0件のものは省く）。
セグメントは等幅でラベルに数字を入れると桁が増えたとき切れるので、件数は別の行に置いている。
左上の絞り込みで **Attendance / FS / Assignment / Final project** のどれかだけに
絞れる（絞り込みは3つのタブすべてに効く）。
Missed は期限を過ぎて残っているもの、Done は済んだもの。Missed からでも後でチェックを付けられる。

To-Do の中身:

| セクション | 中身 |
| --- | --- |
| Check in | 今日の出席。数分で締まるのでここだけ独立させている |
| Next 7 days | FS と毎週の課題。**今日から7日後まで**（今日が土曜なら次の土曜まで） |
| Later | 手で足した、それより先のもの |
| Exams | 試験（日時順） |
| Final projects | 最終課題（締め切り順）。いちばん下にまとめる |

FS は**授業当日から期限（2日後）までの3日間**ずっと出る。
まだ授業が終わっていない回のぶんは出さない。

### 出席の記録

出席のやることは、チェックすると「出た」、スワイプして **Absent** にすると「休んだ」として記録される。
どちらも片付いた扱いになり、やることからは消える。何も記録しなければ Missed に残る
（押し忘れと欠席が区別される）。

授業詳細の **Attendance ▸ Record** で、その授業のこれまでの回と、出た数・休んだ数を一覧できる。
あとから記録を直すのもここから。

### 出席（Attendance）

出席方法は3つから複数選べる。

- **DigiCan**（学内サイト1）
- **Campus Portal**（学内サイト2）
- **In person (roll call)**（先生が呼名して出席をつける）

サイトを使う授業は、授業開始から設定した分数（既定5分）のあいだに自分で出席を押す必要がある。
サイトが1つでも選ばれていれば、授業開始時刻に確認の通知が出る
（通知の2行目に「Open until 9:05」のように締め切りが入る）。
対面だけの授業は自分の操作が要らないため、通知は作られない。
期限が短いので、過ぎた分の出席タスクは次回の同期で自動的に片付けられる。

## 初期データ

初回起動時に作るのは学期とコマの時間だけ（`Koma/Support/SemesterPicker.swift` の `SeedService`）。
授業は入っていないので、時間割の空きマスから自分で足す。土曜は既定で表示する。

| 限 | 時間 |
| --- | --- |
| 1 | 08:40 – 10:10 |
| 2 | 10:20 – 11:50 |
| 3 | 12:40 – 14:10 |
| 4 | 14:20 – 15:50 |
| 5 | 16:00 – 17:30 |
| 6 | 17:40 – 19:10 |

## 画像から時間割を取り込む

時間割タブの右上 **＋ → Import from Image** で、ポータルの時間割のスクリーンショットから
コマを読み取る（`Services/TimetableImporter.swift`）。読み取りは Vision で端末内だけで完結し、
画像はどこにも送らない。写真の権限も要らない（PhotosPicker はアプリ外で動くため）。

仕組み:

1. 1回目は画像全体を読んで、見出しの行と各限の行の位置を掴む
2. **見出しの行だけを細い帯で切って読み直す**。白抜きの曜日は全体読みだと半分ほど読み落とされる
3. 読めた曜日を**週での定位置**（月=0 … 土=5）に置いて直線を当てはめ、列を決める。
   いくつか読み落としても残りの列がずれない
4. **曜日ごとに縦に切って**読み直す。切らずに読むと Vision が
   「火水」「4写真演...Webプ...」のように行をまたいで1件にまとめてしまうため
5. 同じ名前のマスをひとつの授業にまとめる。濁点・半濁点の読み違い（プとフ、ポとボ）は同じ授業として扱う

取り込む前に一覧で名前を直せる。ポータル側で名前が省略されているぶんは省略されたまま入る。

名前が切り詰められて別々の授業が1行にまとまることがある（「Core En…」が6コマあって実は3授業、など）。
その場合は**スワイプして Split** し、**分けたいコマを選んで**新しい名前を付ける。
3授業に分けるならこれを2回繰り返す。
分けたあと同じ名前を付け直せば取り込むときにまた1つの授業になる
（取り込みは行ごとではなく**名前ごと**にまとめる）。

取り込んだあとでも、授業詳細の **Split into another course** で同じことができる。
設定は元の授業から引き継ぎ、やることは新しい授業のぶんとして作り直される。

逆に、別々に入ってしまった授業は授業詳細の **Merge another course into this** でまとめる。
**追加済みの授業は名前を揃えても勝手にはまとまらない**（名前でまとまるのは取り込み画面の中だけ）。
同じ曜日・限が重なるぶんは持ち込まず、試験は引き継ぐ。

画像は切り取らなくてよい。切り取っても結果は変わらない（しきい値はすべて文字の高さを基準にしてある）。

## 学期の複製

設定の学期をスワイプ → **Duplicate** で、授業とコマを引き継いだ学期を作る。
やること・休講・試験はその学期固有なので引き継がない。最終課題の締め切りは新しい学期の終わりに置き直す。

## 試験

授業詳細の **Exams** から、中間・期末などを登録する（1授業に何件でも）。
日時は**その授業の回から選ぶ**（`Mon, Oct 12 · P4 14:20` のような一覧。休講の回は出ない）。
授業と別枠でやる試験は「Another date and time」で日時を直接入れられる。
教室と、範囲・持ち込み可否のメモも持てる。

通知は**2回**。既定は1週間前と前日の19:00で、どちらも授業ごとに変えられる。
前日ではなく当日を選んだときに指定時刻が試験開始を過ぎている場合は、開始1時間前に寄せる。

## 休講

授業詳細の **Cancelled classes** で、回ごとに休講を切り替える。今日のぶんは時間割の
「今日の授業」カードを長押ししても切り替えられる。

休講にした日は、

- 出席・FS・課題のやることを作らない（既にあるものは次の同期で消える）
- 期限の **Before next class** が、その回を飛ばして次の授業を見る
- 時間割と今日のカードで、打ち消し線と `Cancelled` 表示になる

## 振替

休講の一覧で、休講にした日を**左からスワイプ**すると振替を足せる。
授業詳細の **Make-up classes** からも追加できる。

振替は時間割のコマとは別に、その日その限に**1回ぶんの授業**として扱われる。
出席・FS・課題がその日のぶんとして作られ、`Before next class` の「次の授業」にも数えられる。
今日のカードと時間割（今週に入っていれば）に `Make-up` と出る。

## 仕組み

1. 学期の期間と各授業のコマ（曜日 × 限）から授業日を割り出す。
   面倒をみる範囲は**学期の開始**から先120日まで。学期途中で授業を登録しても、
   出席も含めてすでに終わった回のぶんが作られる（期限が過ぎていれば Missed に入る）。
2. 種類ごとの設定にあわせて `TaskItem` を作る。
3. 未完了のものを期限が近い順に60件まで `UNCalendarNotificationTrigger` で登録する。
4. 通知から「Mark as Done」「Remind Tomorrow」を直接操作できる。

同期はアプリ起動時・フォアグラウンド復帰時・設定変更時に走る。
